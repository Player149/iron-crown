# AI 전투 밸런스 실험실 (개발자용)

## 기존 게임 메뉴에서 실행하기

Godot에서 `scenes/main.tscn`으로 게임을 시작(F5)하거나 배포된 웹 게임을 열고, 메인 메뉴의 **AI 자동 전투 · 밸런스 실험실** 버튼을 누릅니다. **10 / 100 / 1000판**을 선택하면 실제 게임 아레나와 AI 전투 로직으로 자동 대전을 순차 실행하며, 진행률과 직업별 승수, 대진별 통계 및 경기별 상세 결과를 화면에 표시합니다. 종료 후 같은 메인 메뉴로 돌아옵니다. 이 기능은 실제 플레이 UI 안에서 실행하므로 웹/모바일에서는 대량 실행 시 브라우저가 느려질 수 있습니다. 최초 검증은 10판으로 진행하세요.

## 기존 별도 테스트 씬 / 명령행에서 실행하기

Godot 에디터에서 `tests/balance_lab.tscn`을 열고 **F6**(현재 씬 실행)을 누르면 1대1 AI 자동 전투 20판을 실행하고 종료합니다. UI 없이 처리하기 때문에 에디터에서는 진행 상황이 출력 창에 표시됩니다. Godot 명령행에서는 다음처럼 반복 수와 시드를 설정할 수 있습니다.

```bash
godot --headless --path . res://tests/balance_lab.tscn -- --runs=100 --seed=421
```

이 스크립트는 실제 아레나의 `start_duel`, `_physics_process`, `CrownFighter.ai_control`, 직업 씬 및 공격 애니메이션의 판정 이벤트를 재사용합니다. 두 캐릭터 모두 AI로 전환하고 60Hz 고정 시간 간격으로 처리합니다. 기존 에디터 플레이와 달리 그래픽을 렌더링하지 않아 반복 실행에 적합합니다. 단, 사용 환경에서 실제 처리 속도와 전투 동등성 검증이 필요합니다. 60초간 승자가 정해지지 않으면 승자를 임의 선정하지 않고 `timeout`으로 기록합니다.

## 결과 읽기

이번 실행의 결과를 화면에서 스크롤해 확인합니다. 대진별로 왼쪽·오른쪽 승수, 시간 초과 횟수, 평균 경기 시간을 표시합니다. 각 경기에는 직업, 승패, 소요 시간, 양측 최종 HP, 받은 피해 추정치, 난수 시드가 표시됩니다. 받은 피해는 틱 사이에 관측된 HP 감소량이므로 같은 틱의 회복에 영향을 받을 수 있습니다.

명령행 실행 시 같은 상세 결과가 콘솔에 출력됩니다. 실험 결과는 메모리에서만 처리합니다.
