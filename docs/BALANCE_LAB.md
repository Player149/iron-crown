# AI 전투 밸런스 실험실 (개발자용)

## 기존 게임 메뉴에서 실행하기

Godot에서 `scenes/main.tscn`으로 게임을 시작(F5)하거나 배포된 웹 게임을 열고, 메인 메뉴의 **AI 자동 전투 · 밸런스 실험실** 버튼을 누릅니다. **10 / 100 / 1000판**을 선택하면 실제 게임 아레나와 AI 전투 로직으로 자동 대전을 순차 실행하며, 진행률 및 종료 직업별 승수를 화면에 표시합니다. 종료 후 같은 메인 메뉴로 돌아옵니다. 이 기능은 실제 플레이 UI 안에서 실행하므로 웹/모바일에서는 대량 실행 시 브라우저가 느려질 수 있습니다. 최초 검증은 10판으로 진행하세요.

## 기존 별도 테스트 씬 / 명령행에서 실행하기

Godot 에디터에서 `tests/balance_lab.tscn`을 열고 **F6**(현재 씬 실행)을 누르면 1대1 AI 자동 전투 20판을 실행하고 종료합니다. UI 없이 처리하기 때문에 에디터에서는 진행 상황이 출력 창에 표시됩니다. Godot 명령행에서는 다음처럼 반복 수와 시드를 설정할 수 있습니다.

```bash
godot --headless --path . res://tests/balance_lab.tscn -- --runs=100 --seed=421
```

이 스크립트는 실제 아레나의 `start_duel`, `_physics_process`, `CrownFighter.ai_control`, 직업 씬 및 공격 애니메이션의 판정 이벤트를 재사용합니다. 두 캐릭터 모두 AI로 전환하고 60Hz 고정 시간 간격으로 처리합니다. 기존 에디터 플레이와 달리 그래픽을 렌더링하지 않아 반복 실행에 적합합니다. 단, 사용 환경에서 실제 처리 속도와 전투 동등성 검증이 필요합니다. 60초간 승자가 정해지지 않으면 승자를 임의 선정하지 않고 `timeout`으로 기록합니다.

## 데이터 파일

- `user://combat_stats/matches.jsonl`: 경기별 기록을 **추가(append)**. 직업, 양측 시작 위치와 레벨, 투자 빌드, 난수 시드, 승패, 시간, 최종 HP와 관측 HP 감소량 포함.
- `user://combat_stats/summary.csv`: 누적 기록 전체에서 직업·상대별 대진 횟수, 승/패/타임아웃과 승부가 결정된 경기의 승률을 집계. 매 실행 시 재생성.
- 파일 위치는 Godot 콘솔에 절대 경로가 출력되며, Godot 에디터의 **프로젝트 → 사용자 데이터 폴더 열기**에서 찾을 수 있습니다.
- `user://`는 에디터나 게임을 껐다 켜도 일반적으로 유지되는 사용자 데이터 폴더입니다. 소스 저장소의 `res://`에 저장하지 않습니다. 브라우저 빌드는 사용자 브라우저별 저장소를 사용하므로 모든 방문자의 데이터를 모으지는 못합니다.
- JSONL과 CSV를 개발 AI에게 전달해 표본 수, 직업별 상성, 시드별 편향을 분석할 수 있습니다. 플레이어 개인 식별 정보는 수집하지 않습니다.

## 제한 및 다음 단계

- 첫 단계는 **1대1 자동 대전만** 지원합니다. 8분 영광의 대관 전체의 고속 시뮬레이션은 아직 미구현입니다.
- HP 감소량은 틱 단위 관측값으로, 회복과 같은 틱에 발생한 피해가 누락될 수 있는 **추정치**입니다. 막기·그로기·스킬 정확도 등은 전투 이벤트별 계측 코드를 추가해야 합니다.
- 엔진 전체 `time_scale`을 조작하지 않습니다. 사람 조작 1대1과 AI 전용 자동전의 전략 차이도 별도로 검증해야 합니다.
- 같은 시드와 역할 교환, 여러 AI 빌드, 버전·밸런스 리소스 해시, 경기 이벤트 로그, 8분 경기 반복 실행과 SQLite/서버 수집은 후속 단계입니다.
- 매우 많은 경기 데이터를 저장할 경우 JSONL/CSV만으로 집계하는 방식은 느려질 수 있습니다. 그때 SQLite로 전환합니다.
