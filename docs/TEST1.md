# IRON CROWN · TEST1 실험판

**브랜치:** `test1` / 원본 `main`에는 반영하지 않음.

이번 버전은 **다양한 Diep.io식 계보 진화와 타이밍 중심 전투의 느낌**을 빠르게 비교하는 실험판이다. 정식 아트, 밸런스, 멀티플레이 서버 구현이나 완성판이 아니다.

## 플레이 방법

1. `test1` 브랜치를 내려받아 Godot 4.5.1에서 `project.godot`을 열고 F5로 실행한다.
2. 게임 시작 → 우측 상단 **일시정지** → **TEST1 · 다음 진화 즉시 체험**을 선택한다.
3. Lv.5에서 시작 계열 12종 중 하나를 고른다. Lv.15에서 해당 계열의 하위 분기를 선택하고, Lv.25에서 최종 형태를 선택한다.
4. 여러 트리를 체험하려면 메뉴로 돌아가 새 게임을 시작한다. 기존 `L` 레벨업 치트와 `B` 보스전 치트도 그대로 동작한다.

## 게임 내용

- **계보형 진화:** Lv.5 → 15 → 25, 총 70개 이상 이름/외형/전투 스타일 변형을 가진 경로 데이터. 각 선택지는 바로 전 단계에 종속된다.
- **공통 조작:** WASD 이동, 왼쪽 클릭 공격, 오른쪽 클릭 막기/일부 클래스 회피, Space 대시, E/R/Q 각 단계의 기술.
- **차별화된 공격:** 창의 긴 찌르기와 돌진, 검의 패링, 도끼의 넓은 베기, 양날도끼 회전, 망치 차징 예고, 대검 한방, 주먹 회피, 쌍검 연속 공격, 낫 끌기, 삽 지면 파동, 해적 후크, 기계 열, 괴물 기본기, 날개 빛 공격.
- **특이 진화:** 주먹 → 기계 팔 → 로봇, 평범한 계열 → 괴수, 삽 → 지하 괴수, 단검/발톱 → 육안육완 거미형, 외눈체 → 마더십, 악기 → 지휘관.
- **자세 게이지:** 공격과 방어 충돌에 따라 누적, 100에 이르면 짧은 자세 붕괴 발생. 짧은 보호시간으로 연속 기절을 억제. 기존 탈진과 별도.
- **패링:** 막기 시작 0.18초 내 정면 공격을 받으면 무효화하고 상대 자세에 압력. 전투 스타일에 따라 적용 여부가 다르다.
- **소환:** 소환·거미·음악 계열에서 따라다니는 동료를 소환할 수 있고, 한 주인당 최대 3마리까지 유지.
- **몬스터 지역:** 외곽 평원(약함), 중간 폐허(재빠름), 왕관 중심부(무거운 강적). 지역별 체력/이동/타격과 경험치가 다름.
- **성장 속도:** 요구 경험치를 줄이고 기본 Lv.40 체력을 260, 스태미나를 170으로 낮춘 실험 밸런스.
- **외형:** 현재는 임시 SVG 스프라이트와 코드로 그린 무기 실루엣/전투 이펙트. 70여 클래스 각각의 고유 정식 아트나 애니메이션은 아직 없음.

## 주의와 테스트 범위

[웹에서 TEST1 열기](https://player149.github.io/iron-crown/test1/) (배포 워크플로 성공 후 접근 가능).

이 브랜치는 한 화면에서 차이를 알아볼 수 있게 만든 테스트이며, 상위 진화의 **고유 수치 및 스킬이 각각 완성된 것이 아니다**. 대부분 전투 패턴은 몇 가지 공통 `combat_style` 원형을 공유하고, 직업 전용 애니메이션은 임시 연출이다.

AI와의 전투만 제공하며 실제 20~25인 실시간 멀티플레이, 서버 연결, 네트워크 타이밍 보정은 구현하지 않았다.

## 테스트 및 빌드

GitHub Actions 워크플로가 `test1` 브랜치의 푸시를 빌드·검증하고, 통과하면 **iron-crown-web-test1** 아티팩트로 웹 실행 파일을 올린다. test1 브랜치의 배포는 본편 main을 동일하게 다시 빌드하여 웹 루트에 그대로 두고, 실험판은 `/iron-crown/test1/` 하위에 별도 배포한다. 기존 본편 저장 경로와 실험판 저장 경로도 분리한다. 테스트 배포에 실패할 경우 Actions 아티팩트로 빌드물을 확인한다.

- `godot --headless --path . --script res://tests/run.gd` : 기존 핵심 전투/보스 회귀 검증(새 성장 수치 반영)
- `godot --headless --path . --script res://tests/layout.gd` : 모바일 세로·가로 UI
- `godot --headless --path . --script res://tests/test1.gd` : 계보, 패링, 자세, 소환, 몬스터 지역

**다음 작업:** 실제 캐릭터 외형과 애니메이션 제작, 서로 다른 분기간 스킬 구성과 밸런스, 실기기 입력 체험, 성능 측정, 온라인 구조 분리.


## 데스매치 AI 모드 (2026-10-11, TEST1 전용)
- 시작: TEST1 초기 화면의 "8분 데스매치 · AI 9명 (NEW)" 버튼. 메인 모드나 main 브랜치 변경 없음.
- 매칭 없이 사람 1명과 AI 9명이 동일한 Lv.1 기사로 8분 경기를 치르는 로컬 시뮬레이션이다. PvP 네트워크/진짜 매칭/서버는 구현되지 않았다.
- 기존 세계에서 별도 데스매치 씬을 사용한다. 65개 경험치 결정이 맵에 분포하고 수집 시 XP와 점수를 얻는다. 결정을 주워 레벨업하고 5/15/25레벨에 TEST1 계보 진화 선택을 한다. AI는 주변 적과 싸우거나 XP 결정을 찾아 성장한다.
- 득점: XP 획득량 약 8.5%만큼(최소 1점), 적 기사 처치 +100점. 종료 시 점수 순위가 승패 기준이다.
- 사망: 3초 뒤 별도 지점에서 보호 시간을 가지고 부활한다. 진화된 직업과 이미 선택한 강화는 유지한다. 마지막 진화 체크포인트 이후의 누적 XP 중 20%를 잃고 레벨도 그만큼 하락할 수 있다. 최소 레벨은 현재 진화 단계의 5/15/25(미진화 1)이다.
- 최고 도달 레벨에만 자동 스탯/선택 보상을 주므로 죽었다가 재성장하면서 동일 레벨을 무한 반복해 강화하지 못한다. 매 3레벨에 자동 특성 1개를 얻고, 플레이어는 10/20/30/40레벨에서 추가 선택을 한다.
- AI와 게임 로직은 기존 TEST1의 공격 타이밍/막기/패링/무기 스타일을 재사용한다. 몬스터나 주기 보스는 이 모드에서 비활성화. 기존 TEST1 모드에는 영향을 주지 않는다.
- 리스폰과 순위 결과 및 XP 감소 규칙 회귀 테스트: tests/deathmatch.gd. 실제 플레이 밸런스와 모바일 조작 확인 필요.
